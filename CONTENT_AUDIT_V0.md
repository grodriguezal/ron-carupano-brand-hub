## Convención sugerida para GitHub Issues

Usar etiquetas como:

- `strategy`
- `visual-identity`
- `verbal-identity`
- `portfolio`
- `digital`
- `trade-marketing`
- `compliance`
- `assets`
- `governance`
- `needs-validation`

Cada issue debería incluir: objetivo, contenido actual, decisión necesaria, responsables, activos requeridos y criterio de aprobación.
